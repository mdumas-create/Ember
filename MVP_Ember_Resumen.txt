==================================================
        EMBER - MVP SOCIAL NETWORK LOGS
==================================================
Fecha: 26 de Marzo, 2026
Estado: MVP Production-Ready (v3.0)
==================================================

--- 1. ARQUITECTURA Y ESCALABILIDAD (BACKEND) ---
- Stack: Node.js + Express + TypeScript + Prisma + PostgreSQL + Redis.
- Escalado Horizontal:
  * Redis Adapter para WebSockets (Socket.io) integrado.
  * Soporte para balanceo de carga NGINX con sticky sessions.
  * Feature Flags: Sistema dinámico para controlar lanzamientos (/api/config/flags).
- Rendimiento & Calidad:
  * Caching agresivo con Redis (Feed, Sugerencias).
  * Pruebas de Carga: Scripts base con K6 para validar latencia < 500ms (p95).
  * Tests de Integración: Cobertura de flujos críticos (Auth, Posts).

--- 2. EXPERIENCIA DE USUARIO Y RETENCIÓN ---
- Mobile App:
  * Stack: React Native + Expo.
  * Preparada para Producción: Configuración EAS Build y FCM nativo.
  * Offline-first: Cola de acciones (posts, chat, likes) con sincronización automática.
- Engagement & Gamificación:
  * Notificaciones Inteligentes: Recordatorios de racha (streak) y avisos de inactividad vía Bull Queue.
  * Widgets de Actividad: Visualización de racha 🔥, reputación ⭐ y nivel en el perfil.
- Contenido Social:
  * Stories Avanzadas: Visor con progreso, autoplay y reacciones efímeras.
  * Chat Full: Texto, audio, video, búsqueda y reacciones.
  * Compartir: Integración nativa para compartir posts en redes sociales externas.

--- 3. SEGURIDAD Y MODERACIÓN ---
- Moderación Activa:
  * Panel de Administración: Pantalla exclusiva para moderadores para gestionar reportes.
  * Filtro de Profanidad: Sistema centralizado y configurable de palabras prohibidas.
- Privacidad:
  * Cuentas Privadas: Los usuarios pueden restringir su contenido solo a seguidores.
  * Cumplimiento Legal: Pantallas de Términos y Privacidad integradas.
- Protección:
  * Rate limiting, sanitización anti-XSS y validación con Zod.

--- 4. OPERACIONES (DEVOPS) ---
- Infraestructura:
  * Docker Compose: Postgres + Redis + Backend listo para producción.
  * RUNBOOK.md: Documentación completa para despliegue, escalado y backups.
- Observabilidad:
  * Logging con Winston/Morgan. Monitoreo de salud (/health).
  * Sentry integrado en Backend y Frontend.
- Backups:
  * Estrategia de pg_dump automatizado con subida a S3.
